Getting Started from GitHub

What you'll find here: The path a developer should follow after downloading or cloning the repository. Exact dependency commands should remain synchronized with the root README and project package files.

1. Get the repository

Preferred:

git clone <repository-url>
cd <project-directory>

Or download the GitHub ZIP, extract it, and open a terminal in the project root.

2. Install project prerequisites

Use the versions documented by the project. Avoid guessing versions on a new machine. Install the required runtime, package manager, Git, and Microsoft 365 Agents Playground tooling used by the repository.

3. Install project dependencies

Run the dependency-install command defined by the current project package configuration.

4. Start the chatbot locally

Start the chatbot so that its local messaging endpoint is available at the address configured by the project.

5. Start Microsoft 365 Agents Playground

agentsplayground -e http://localhost:3978/api/messages -c emulator

6. Run smoke tests

  • Known question → expected support answer.
  • Ambiguous question → one clarification attempt; repeated ambiguity → offer IT review.
  • Unsupported question → preserve original question, rephrase, then unresolved handling if still unmatched.

7. Add or maintain support topics

Approved IT procedures can be added through the Managing Support Data workflow. The AI Support Topic Prompt can format approved procedures, identify files to review, and generate test questions.

Tip: If you do not have access to a company's Microsoft Teams environment, continue with the Agents Playground guide. You can still validate the current local MVP.
