MVP EXAMPLES

Sample Conversations

What you'll find here: Example conversations showing the three main behaviors the MVP is designed to demonstrate: a known support question, an ambiguous question that needs clarification, and an unresolved question that should be recorded for IT review.

1. Known support question

User

How do I create an email signature in Outlook?

Chatbot

I found a matching support topic for creating an Outlook email signature. Here are the approved steps.

Chatbot

Was this helpful? Please answer yes or no.

User

Yes.

2. Ambiguous question

User

How do I add something to my Outlook email before I send it?

Chatbot

I found more than one possible support topic. Could you provide a little more detail about what you're trying to do?

User

I want to attach a document.

Chatbot

Thanks. I found the support topic for attaching a document to an Outlook email.

3. Unresolved question

User

My application shows an error that is not in the support list.

Chatbot

I could not confidently match that problem. Please rephrase it and include the application name or exact error message.

User

The same error appears after I rephrase it.

Chatbot

I still could not match the problem. Would you like to submit this problem for IT review?

User

Yes.

Chatbot

Your problem has been submitted for IT review.

4. Repeated ambiguity

User

The signature disappears when I do something with my email.

Chatbot

I found more than one possible Email solution. Could you provide a little more detail about what you're trying to do?

User

My Outlook signature disappears only when I send messages to people outside the company.

Chatbot

I still couldn't determine the correct solution. Would you like to submit this problem for IT review?

The chatbot allows one clarification attempt. If the result remains ambiguous, it offers IT review instead of repeatedly asking for more detail.

Unresolved record details

Submitted unresolved issues preserve conversationId, the user, the original question, the rephrased or final clarifying question, and the submission time. Local testing uses user for identity. Timestamps use ISO 8601 local runtime time with the UTC offset, for example 2026-09-15T14:03:22.892-07:00.

What these examples are meant to prove

ScenarioMVP behavior
Clear matchReturn the approved support topic and ask whether it was helpful.
More than one plausible matchAsk for clarification once; if still ambiguous, offer IT review.
No reliable match after rephrasingOffer unresolved-problem submission for IT review.
