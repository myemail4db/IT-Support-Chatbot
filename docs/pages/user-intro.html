Using the Chatbot

What you'll find here: A non-technical introduction to the chatbot, what it is meant to help with, how a conversation works, and why chat is useful alongside voice support.

What is the chatbot?

The chatbot is an additional IT-support communication channel inside Microsoft Teams. A user describes an IT problem conversationally. The chatbot analyzes the request, looks for the best matching approved support topic, and responds with the appropriate support information.

What happens when I ask a question?

User describes a problem
        ↓
Chatbot looks for what the user is trying to do
        ↓
Chatbot identifies what the problem is about
        ↓
Chatbot uses additional context
        ↓
Best support topic is selected
        ↓
Answer, clarification, or unresolved handling

Why chat in addition to voice?

Chat does not have to replace voice support. It provides another path when voice quality is poor or when technical information is easier to send in writing. Users can paste exact error messages, provide screenshots, and refer back to the conversation history.

If the chatbot is unsure

The chatbot should not guess. It can ask the user for more information. If the issue remains unresolved after the supported clarification flow, the chatbot can offer to record it for IT review. The original question is preserved along with the later rephrase or clarification so IT has more context.
