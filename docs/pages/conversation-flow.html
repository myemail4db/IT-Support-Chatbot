Conversation Flow

What you'll find here: How the chatbot handles clear matches, ambiguous questions, rephrasing, and unresolved issues.
User question
     ↓
Analyze all topics
     ↓
Clear match? ── Yes ──→ Return support answer
     │
     No
     ↓
Ambiguous? ── Yes ──→ Ask for clarification
     │
     No / still unclear
     ↓
Ask user to rephrase
     ↓
Analyze again
     ↓
Still unresolved
     ↓
Offer to submit for IT review

Design principle

The chatbot should prefer asking for clarification over confidently returning the wrong support topic.
