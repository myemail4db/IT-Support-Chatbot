Understanding the Chatbot as a Developer

What you'll find here: The developer view of the chatbot, including its matching pipeline, local testing path, support data, and where to go next.

Core processing flow

Microsoft Teams-style message
        ↓
Conversation processing
        ↓
Intent matching
Object matching
Context matching
        ↓
Score all support topics
        ↓
Best result
        ↓
FOUND / AMBIGUOUS / UNRESOLVED

Current support data

Approved support topics are stored in data/support/support-data.json. Semantic vocabulary is stored separately under data/semantics/. This keeps approved answers separate from the language used to understand user questions.

Recommended developer path

  1. Read Architecture.
  2. Follow Getting Started from a fresh repository download.
  3. Use Microsoft 365 Agents Playground for local testing.
  4. Run known, ambiguous, and unsupported test questions.
  5. Review MVP Security before expanding connectivity.
