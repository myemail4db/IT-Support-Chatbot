# Documentation Mini-Site

Open `docs/index.html` in a browser.

The site is intentionally static HTML/CSS/JavaScript so it can be viewed locally after cloning the repository.

## Structure

- `docs/index.html` - documentation home
- `docs/pages/` - short topic pages
- `docs/assets/styles.css` - shared styling
- `docs/assets/search.js` - client-side keyword search

## Integration

Copy the `docs/` folder into the project root. The root project README can then point users to:

`docs/index.html`
